# 用户

## 模块SCOPE
```
user
```
## 模块介绍

用户属于CRM基石之一。CRM中所有单据基本有用户信息，特别各单据中的处理人，创建人，更新人等user_id都可以在这里找到对应的用户信息，包括职位，中文名，邮箱等等，该模块接口中信息非常重要和涉及邮箱隐私，请注意使用。新对接的同学认真看下文档，也请注意接口名称右边的小状态。

| 接口状态 |  |
| --- | --- |
| 已废弃 | 不要使用 |
| 将废弃 | 不建议使用 |
| 已发布 | 正常使用 |
