# 销售订单

## 模块SCOPE
```
invoices
```
## 模块介绍

销售订单属于CRM交易模块的很重要的一环。CRM订单参数字段多，可以根据自身情况传入，请新对接的同学认真看下文档，也请注意接口名称右边的小状态。

| 接口状态 |  |
| --- | --- |
| 已废弃 | 不要使用 |
| 将废弃 | 不建议使用 |
| 已发布 | 正常使用 |


1、[销售订单新建/编辑](api-3478252.md)
> 新建/编辑接口是打通外部系统与CRM订单的重要途径。

> 自定义字段可以通过接口【销售订单字段列表】获取，若自定义字段是多选，单选字段，可以在该字段信息的ext_info中找到枚举值。

> 部分订单系统字段要传入的是枚举值，可以通过接口【销售订单枚举】获取。

> 订单中要传入的当前处理人、业绩归属人等可以用过接口【用户-用户列表】等获取用户ID。

> 目前订单明细只支持以product_id唯一，即订单内有多个相同的product_id的明细只保留其中一个明细。

3、[销售订单详情](api-3478251.md)

4、[销售订单字段列表](api-3478253.md)
> 这里面包含了系统字段和自定义字段，系统字段为英文加下划这些形式，自定义字段都是数字。
> 每个企业的自定义字段都不一样，所以若要获取自定义字段的值路径为：先通过【销售订单字段】接口获取字段的ID，再通过【销售订单详情接口】和字段ID，找到对应字段的值。
